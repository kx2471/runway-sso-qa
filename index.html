미리보기 화면에서는 자동화가 실행되지 않습니다

iPad·iPhone의 파일 앱이나 메일, Gmail·Google Drive의 미리보기는 HTML 안의 스크립트를 실행하지 않습니다. 아래는 Mock 화면과 자동화 테스트 목록입니다. 컴퓨터의 Chrome·Safari·Edge로 이 파일을 열면 테스트가 화면을 직접 조작하는 데모가 실행됩니다. 지금 바로 실행해 보려면 온라인 데모를 여세요.

데모에서 실행되는 테스트 33개

Admin SSO 설정

  • ADM-001관리자는 SSO 설정에 접근하고 미연동 상태를 본다
  • ADM-002일반 사용자는 SSO 설정에 접근할 수 없다
  • ADM-004Google Workspace 연동 설정을 저장하면 연동된다
  • ADM-005Microsoft Entra ID 연동 설정을 저장하면 연동된다
  • ADM-006잘못된 Client Secret이면 연동되지 않고 버튼도 없다
  • ADM-007필수값이 누락되면 저장되지 않는다

단일 IdP · 변경

  • ONE-001Google 연동 중에는 Entra ID를 선택할 수 없다
  • ONE-004Google → 해제 → Entra ID 전환 후 같은 계정·데이터로 로그인된다
  • ONE-006API로 두 번째 IdP를 등록하면 거부된다
  • ONE-008해제 후 새 IdP 연동이 실패해도 로그인 수단을 잃지 않는다

로그인 페이지 UI

  • UI-001미연동 상태에서는 SSO 버튼이 없다
  • UI-002Google 연동 시 [Google 로그인] 버튼만 표시된다
  • UI-003Entra ID 연동 시 [MS 로그인] 버튼만 표시된다
  • UI-004연동 해제 후 SSO 버튼이 사라진다

SSO 로그인

  • LGN-001이메일이 일치하는 기존 계정으로 로그인된다
  • LGN-003대상 그룹이 아닌 IdP 사용자는 거부된다
  • LGN-004그룹에서 제거된 사용자는 SSO가 거부되고 ID/PW도 열리지 않는다
  • LGN-005개인 계정은 거부되고 계정이 생성되지 않는다

신규 계정 생성

  • NEW-001일치하는 계정이 없으면 최초 로그인 시 생성된다
  • NEW-002다시 로그인해도 계정이 중복 생성되지 않는다

ID/PW 로그인 차단

  • BLK-001연동된 계정은 올바른 비밀번호로도 ID/PW 로그인할 수 없다
  • BLK-002IdP 그룹에 없는 계정은 ID/PW 로그인을 계속 쓴다
  • BLK-003비밀번호 재설정으로 SSO를 우회할 수 없다

연동 해제

  • UNL-001확인 팝업을 거쳐 연동을 해제한다
  • UNL-002해제 후 연동 전 비밀번호로 기존 계정에 로그인된다
  • UNL-003SSO로 생성된 계정은 해제 후 비밀번호를 설정해 로그인한다
  • UNL-004해제 전에 시작한 SSO 로그인은 해제 후 완료되지 않는다

데이터 무결성

  • DAT-001연동 후 프로젝트·모델이 연동 전과 같다
  • DAT-004해제 후 데이터가 연동 전과 같다
  • DAT-006연동 중에 만든 프로젝트가 해제 후에도 남아 있다
  • DAT-007연동·해제 후에도 내부 사용자 ID가 같다
  • DAT-010새로 생성된 계정에 다른 계정의 데이터가 연결되지 않는다
  • DAT-011같은 IdP로 재연동하면 기존 계정과 다시 매칭된다
